Bulk-Cook Companion — Overview

A personal app for planning, cooking, and tracking bulk meals with a focus on macro/calorie awareness per portion and reusable recipes.

Core purpose

Make it easy to repeatedly cook large batches of meals, know exactly what's in each portion nutritionally, and streamline the shopping side of it.

What it does

Recipes

- Save recipes with ingredients (quantity + unit), step-by-step instructions, and default batch size (e.g., "makes 8 portions").
- Edit, duplicate, and re-cook saved recipes any time.
- Scale a recipe up or down — ingredient quantities adjust automatically.

Ingredients & nutrition

- Maintain a personal ingredient library with calories and macros (protein / carbs / fat, possibly fibre) per unit (e.g., per 100g, per ml, per item).
- When building a recipe, the app calculates total calories/macros and per-portion calories/macros automatically.
- Reuse ingredients across recipes — update one entry, all recipes using it stay accurate.

Shopping list

- Add a recipe's ingredients to a shopping list with one tap, scaled to the batch size you're cooking.
- Combine ingredients across multiple recipes into a single consolidated list (e.g., onions from 3 recipes = one line item).
- Tick items off as you shop.

Cooking

- Pull up a recipe's instructions in a clean, cook-friendly view while you're in the kitchen.

Out of scope (intentionally)

- Use-by / expiry tracking
- Freezer location or multi-house features
- Meal scheduling / weekly planners
- Social / sharing features
