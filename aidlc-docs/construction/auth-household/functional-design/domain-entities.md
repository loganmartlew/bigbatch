# Unit 1: Auth & Household — Domain Entities

## Entity: User

Already defined in Unit 0 schema (`users` table). Auth unit reads/writes these fields:

| Field          | Type                         | Rules                                          |
| -------------- | ---------------------------- | ---------------------------------------------- |
| id             | integer (PK, auto-increment) | Immutable                                      |
| email          | text (unique, not null)      | Lowercase, trimmed, validated as email format  |
| firstName      | text (not null)              | Trimmed, 1–50 chars                            |
| lastName       | text (not null)              | Trimmed, 1–50 chars                            |
| hashedPassword | text (not null)              | argon2id hash, never returned in API responses |
| createdAt      | text (ISO 8601)              | Set on INSERT                                  |
| updatedAt      | text (ISO 8601)              | Set on INSERT, updated on password change      |

### User Public Shape (API response)

```typescript
{
  id: number;
  email: string;
  firstName: string;
  lastName: string;
  createdAt: string;
}
```

`hashedPassword` is **never** included in any API response.

## Entity: Session

Already defined in Unit 0 schema (`sessions` table). Managed by Lucia Auth.

| Field     | Type                 | Rules                                 |
| --------- | -------------------- | ------------------------------------- |
| id        | text (PK)            | Generated by Lucia (random token)     |
| userId    | integer (FK → users) | Not null                              |
| expiresAt | text (ISO 8601)      | 30 days from creation, no auto-extend |
| createdAt | text (ISO 8601)      | Set on INSERT                         |

Sessions are **user-level only** — not tied to any specific household. A single session covers all households the user belongs to.

## Entity: Household

Already defined in Unit 0 schema (`households` table).

| Field     | Type                         | Rules                                  |
| --------- | ---------------------------- | -------------------------------------- |
| id        | integer (PK, auto-increment) | Immutable                              |
| name      | text (not null)              | Trimmed, 1–100 chars                   |
| ownerId   | integer (FK → users)         | Set on creation, transferable (future) |
| createdAt | text (ISO 8601)              | Set on INSERT                          |
| updatedAt | text (ISO 8601)              | Set on INSERT, updated on name change  |

### Household Public Shape

```typescript
{
  id: number;
  name: string;
  ownerId: number;
  createdAt: string;
}
```

---

## Entity: UserHousehold (Join Table)

Already defined in Unit 0 schema (`user_households` table).

| Field       | Type                                    | Rules         |
| ----------- | --------------------------------------- | ------------- |
| userId      | integer (FK → users, composite PK)      | Not null      |
| householdId | integer (FK → households, composite PK) | Not null      |
| role        | text enum ("owner" / "member")          | Not null      |
| joinedAt    | text (ISO 8601)                         | Set on INSERT |

### Membership Public Shape

```typescript
{
  userId: number;
  householdId: number;
  role: "owner" | "member";
  joinedAt: string;
  // Joined with user data when listing members:
  user?: { firstName: string; lastName: string; email: string };
}
```

## Entity: HouseholdInvite

Already defined in Unit 0 schema (`household_invites` table).

| Field       | Type                         | Rules                                              |
| ----------- | ---------------------------- | -------------------------------------------------- |
| id          | integer (PK, auto-increment) | Immutable                                          |
| householdId | integer (FK → households)    | Not null                                           |
| token       | text (unique, not null)      | 32-byte URL-safe base64 string (for link sharing)  |
| code        | text (unique, not null)      | 6-char uppercase alphanumeric (for verbal sharing) |
| createdBy   | integer (FK → users)         | Must be household owner                            |
| expiresAt   | text (ISO 8601)              | 24 hours from creation                             |
| createdAt   | text (ISO 8601)              | Set on INSERT                                      |

### Invite Public Shape

```typescript
{
  link: string; // Full URL with token: {FRONTEND_URL}/join?token={token}
  code: string; // 6-char code
  expiresAt: string; // ISO 8601
}
```

## Entity: PasswordResetToken (New)

Not in the current schema — **needs to be added** in this unit.

| Field     | Type                         | Rules                          |
| --------- | ---------------------------- | ------------------------------ |
| id        | integer (PK, auto-increment) | Immutable                      |
| userId    | integer (FK → users)         | Not null                       |
| token     | text (unique, not null)      | 32-byte URL-safe base64 string |
| expiresAt | text (ISO 8601)              | 1 hour from creation           |
| usedAt    | text (ISO 8601, nullable)    | Set when token is consumed     |
| createdAt | text (ISO 8601)              | Set on INSERT                  |

Single-use tokens. Once used (`usedAt` is set), the token cannot be reused.
