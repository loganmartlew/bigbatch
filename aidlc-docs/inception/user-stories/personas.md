# BigBatch — User Personas

## Persona 1: Sam — The Primary Cook

| Attribute          | Detail                                                                                                                                                                                                                          |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Name**           | Sam                                                                                                                                                                                                                             |
| **Role**           | Primary household cook / household owner                                                                                                                                                                                        |
| **Goals**          | Efficiently plan and execute large batch cooks; know exactly what's in each portion; minimise shopping trips by consolidating lists; build a reusable recipe library over time                                                  |
| **Frustrations**   | Manually calculating nutrition when scaling recipes; forgetting ingredients at the store because the list was incomplete; losing track of what was cooked when and how it turned out                                            |
| **Tech Comfort**   | Comfortable with web and mobile apps; expects things to "just work" in the kitchen — no fiddly interactions while hands are messy                                                                                               |
| **Typical Usage**  | Plans a cook session on laptop (web) — picks recipes, scales to target portions, generates shopping list. Shops with phone (mobile) — ticks off items. Cooks with phone propped up (mobile, cook mode). Logs the cook afterward |
| **Device**         | Laptop (web) for planning; iPhone or Android phone (mobile) in the kitchen and at the store                                                                                                                                     |
| **Household Role** | Owner — created the household, manages membership                                                                                                                                                                               |

## Persona 2: Alex — The Household Member

| Attribute          | Detail                                                                                                                                                                |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Name**           | Alex                                                                                                                                                                  |
| **Role**           | Household member (partner/flatmate)                                                                                                                                   |
| **Goals**          | Check what's available to eat and its nutrition; occasionally cook a batch using a saved recipe; contribute new recipes; help with shopping                           |
| **Frustrations**   | Not knowing what Sam already planned to cook; being unable to add missing items to the shopping list; having to ask Sam for recipe details                            |
| **Tech Comfort**   | Uses apps daily but prefers minimal interaction — wants to quickly find information without navigating deep menus                                                     |
| **Typical Usage**  | Checks the shopping list on phone before heading to the store; browses recipes to decide what to cook; logs a cook event; occasionally adds a new recipe of their own |
| **Device**         | Primarily phone (mobile)                                                                                                                                              |
| **Household Role** | Member — joined via invite link or code                                                                                                                               |

---

## Persona-to-Story Mapping

| Persona                 | Primary Story Areas                                                                                                                                       |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Sam (Primary Cook)      | Recipe creation/editing/scaling, ingredient library management, shopping list generation, cook mode, cook history logging, household management (invites) |
| Alex (Household Member) | Recipe browsing, shopping list usage (tick-off), cook mode, cook history logging, joining a household                                                     |
